# 🎯 AI-Based Career Recommendation System

An AI-powered career recommendation system that analyzes a student's
skills and interests to recommend suitable career paths.

## 📌 Project Overview

Students often have difficulty identifying suitable career options
based on their existing skills and interests.

This project uses Natural Language Processing techniques and
cosine similarity to compare a student's profile with predefined
career profiles.

## 🚀 Features

- Student profile input
- Skill selection
- Interest selection
- AI-based career matching
- Career match percentage
- Top career recommendations
- Skill-gap analysis
- Personalized learning roadmap
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- TF-IDF
- Cosine Similarity

## ⚙️ How It Works

1. Student enters their name.
2. Student selects skills.
3. Student selects interests.
4. The system creates a student profile.
5. TF-IDF converts the profile into numerical features.
6. Cosine similarity compares the profile with career profiles.
7. The system generates career recommendations.
8. Skill gaps and a learning roadmap are displayed.
